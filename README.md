# Чайный Бум — локальная копия публичной части

Клиентская реализация публичных страниц [teaboom.ru](https://teaboom.ru) на TypeScript и React. Это демо для просмотра каталога, поиска, фильтров и корзины в браузере. Заказы, вход, избранное и оплата на оригинальный сайт не уходят.

Цены, наличие, тексты и фото сохранены **15.10.2026** с публичных страниц (через [r.jina.ai](https://r.jina.ai) и снимки [web.archive.org](https://web.archive.org)). Они могут отличаться от актуальных.

## Запуск

Нужны Node.js 20+ и npm.

```bash
npm install
npm run dev
```

Откройте адрес, который покажет Vite (обычно `http://localhost:5173`).

Сборка и просмотр production-бандла:

```bash
npm run build
npm run preview
```

Проверка типов: `npm run typecheck`.

## Что работает локально

- Каталог с URL вида `/category-<slug>` и карточки `/product/<slug>`.
- Поиск с подсказками, фильтры (`pack`, `sub`, `sale=1`) и сортировка (`sort`).
- Переключатель фасовки меняет цену, старую цену и артикул.
- Корзина в `localStorage`: количество, сумма, удаление, сохранение после перезагрузки.
- Мобильное меню, мега-меню каталога, вкладки на карточке товара.
- Формы контактов и оформления заказа — только клиентская проверка, без отправки.
- Явные демо-состояния вместо «мертвых» кнопок: нет `href="#"`.

Ключи `localStorage`: `teaboom:cart`, `teaboom:recently-viewed`, `teaboom:cookie-consent`, `teaboom:announcement-dismissed`.

## Ограничения

Это **не** полноценный магазин и **не** копия серверной логики teaboom.ru.

- Сохранены 273 товара и 28 изученных разделов (в основном первые страницы листингов). На сайте разделов больше, у части из них по 2–7 страниц.
- Полные карточки (описание, свойства, похожие товары) есть у 10 товаров; у остальных описание — ссылка на оригинал.
- `/pricelist` и `/login` на оригинале требуют входа — здесь страница-заглушка со ссылкой на teaboom.ru.
- `/checkout-dispatcher` на оригинале не изучался (оформление могло создать заказ). Локально это демо-форма.
- `/page/cookie-policy` на оригинале содержит только заголовок.
- `/product/ananasovij-ulun-tajvan` на оригинале отдаёт 404 — в каталог не включён.
- Формы не создают заказ, аккаунт или обращение.
- Email авторов отзывов не сохранялись.
- Часть фото не скачалась из архива; вместо них показывается «Фото недоступно».

Подробное соответствие URL ↔ маршрутов — в [SITE_MAP.md](SITE_MAP.md).

## Структура (FSD без лишнего)

```
src/
  app/         маршруты, layout, глобальные стили
  pages/       страницы: home, category, product, search, cart, checkout, info…
  widgets/     header, footer, catalog, product-details, product-carousel…
  features/    add-to-cart, catalog-filter, catalog-sort, search-products, формы
  entities/    product, category, cart, review, info-page (+ JSON-данные)
  shared/      UI, конфиг сайта, localStorage, валидация
public/images/ логотип, слайды, иконки, сохранённые фото
```

Стек: Vite 6, React 19, TypeScript, react-router-dom 7, обычный CSS. Без Bootstrap и готовых шаблонов магазина.

Импорты идут только «вниз» по слоям. У слайсов публичный `index.ts`. Фичи не импортируют другие фичи, виджеты — другие виджеты.

## Данные

Тексты, цены и структура собраны с публичных HTML-страниц 15.10.2026. Изображения — из публичных URL и архивных снимков того же домена. Закрытые API, личный кабинет и учётные данные не запрашивались.
